Frontend (Next.js + TypeScript + Tailwind)

Run locally:

1. Install dependencies

```bash
cd frontend
npm install
```

2. Start dev server

```bash
npm run dev
```

The app will be available at http://localhost:3000

Notes:
- The page fetches `GET /businesses` (relative path). Ensure backend is reachable at the same host/port or configure a proxy/CORS.
